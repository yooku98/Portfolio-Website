# William Thompson — Portfolio

Personal portfolio for William Thompson, an SME dashboard and analytics developer (Python, React, Tableau). It showcases featured projects, work experience, testimonials, an FAQ and fixed-price service packages.

**Live site:** https://yooku98.github.io/Portfolio-Website/

## Pages

| Page | Purpose |
|---|---|
| `index.html` | Main portfolio: skills, featured projects, experience, testimonials, FAQ, contact |
| `gadget-sales.html` | Case study: Gadget Sales dashboard (Tableau Public) |
| `inventory-sales.html` | Case study: Inventory & Sales Analytics Dashboard |
| `business-performance.html` | Business performance analysis write-up |
| `receipt-generator.html` | Copy of the receipt generator tool (YookuInc branding; the standalone version lives in [receipt-generator](https://github.com/yooku98/receipt-generator)) |
| `William_Thompson_CV.pdf` | Downloadable CV |

## Stack

Static HTML with inline CSS/JS. It includes structured data (JSON-LD) for search engines, Open Graph tags, and a web app manifest with icons. No build step.

## Run locally

```bash
python3 -m http.server 8000
```

## Deployment

Served by GitHub Pages from the root of `main`.
